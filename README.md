# 🍽️ Recipe Finder Android App

A modern Android application built with Java and Material Design 3 that allows users to discover meals, explore recipe details, save favourite recipes locally, and browse meals by category.

---

# 📱 Features

## 🔎 Search Meals

Search meals instantly by name using TheMealDB API.

## 🏷️ Category Filters

Browse meals using interactive category chips such as:

* 🥩 Beef
* 🍗 Chicken
* 🍖 Lamb
* 🦐 Seafood
* 🥗 Vegetarian
* 🍝 Pasta
* 🥓 Pork
* 🍳 Breakfast
  

## 📖 Recipe Details

View:

* Meal image
* Meal name
* Category
* Country of origin
* Ingredients and measurements
* Cooking instructions

## ⭐ Favourites System

Save recipes locally using Room Database and manage favourites offline.

## 📤 Share Recipes

Share recipes using Android’s native share sheet.

## 🌐 Network State Handling

The app detects internet connectivity and displays:

* Loading states
* Offline messages
* Retry options
* Error handling

---

# 🛠️ Technologies Used

* Java
* Android Studio
* Material Design 3
* RecyclerView
* Room Database
